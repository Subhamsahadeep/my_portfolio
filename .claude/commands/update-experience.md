The user will provide a repo path. Your task:

1. Explore the repo: `git log`, package.json, architecture, key files
2. Extract SMART achievements (Specific, Measurable, Achievable, Relevant, Time-bound)
3. Read `src/app/components/workExperience/details.tsx` and `src/app/data/resume-data.ts`
4. Update both files with enriched, evidence-based achievements
5. Focus on engineering craftsmanship: what was technically hard, patterns used, measurable impact
6. Verify build works
7. Summarize changes
